# Not Your Type — Fixes v4

## Mass-bunk privacy and accuracy
- Mass-bunk detection runs before generic timetable/data routing.
- The group receives one fixed, non-identifying line. The mass-bunk group reply is not generated by the LLM and does not receive timetable or attendance context.
- Individual warnings are sent privately; the owner report contains aggregate counts only.
- Stored run summary contains only a class count, not timetable course codes.
- Matching uses exact normalized course code or exact normalized subject name to avoid charging absences to similar courses.
- Repeated sessions are counted separately by time slot; parallel timetable rows in the same slot count as one session.
- Attendance projections use present/total counts and skip invalid data rather than emitting NaN or misleading percentages.
- Group unknown count is estimated from WhatsApp group member count minus linked Pod accounts.

## Group mute commands
- Natural-language variants such as “stop talking in Photography Club group”, “mute Photography Club group”, and Hinglish equivalents are recognized.
- A group is disabled automatically only on an exact normalized name match. If the name is misspelled, ambiguous, or not found, Chintu lists ranked group candidates and waits for a numeric choice.

## Privacy, alerts, and persona
- Attempts to extract internal instructions/configuration in groups and DMs generate a private owner alert and are handled with a deflection.
- Group memory retrieval can include group context and non-Pod private memories for personalization, but Pod/attendance/bunk/marks/credential content is filtered; private facts are not emitted as group facts.
- Any individual Pod question (attendance, bunk, marks, etc.) in a group redirects to DM, even if it names another student. Persona instructions prohibit revealing private-DM facts and personal Pod data in groups.
- Conversation starters have more topic variety and should not default to attendance/class jokes.
- Replies are instructed to stay on topic and use light flirting only when clearly reciprocated.
- DM approval opening lines are more context-aware without repeating the person's potentially sensitive first message.
